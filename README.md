# Arduino-Blackjack
Using an Arduino Uno and a custom 16x2 LCD Board, we created a fully playable Blackjack experience. It handles a full 52 deck, shuffling, custom card icons, and many of the most common edge cases. It also features a bank, where you can store and withdraw money, including loans when you inevitably lose it all.

# Installation
Running this program requires the Arduino IDE, which can be downloaded [here.](https://www.arduino.cc/en/software/)
This also requires a specific setup for your Arduino board. In order to do this correctly, please reference the screenshot I have attached at the bottom.
From there, its plug and play. Connect your Arduino, upload the file, and gamble! 

# Features and Technology Stack
Bets are adjusted using a potentiometer, and upon bet confirmation, the second potentiometer is used to adjust bet amount. The pushbutton is used to start/stop the game, and our screen displays all necessary information including custom icons for the different suits.
