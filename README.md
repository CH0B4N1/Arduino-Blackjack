# Arduino-Blackjack
Using an Arduino Uno and a custom 19x2 LCD Board, we created a fully playable Blackjack experience. It handles a full 52 deck, shuffling, custom card icons, and many of the most common edge cases.

# Installation
Running this program requires the Arduino IDE, which can be downloaded [here.](https://www.arduino.cc/en/software/)
